## Complex Model Example

### Input Model

```python
from sqlmodel import SQLModel, Field
from typing import Optional
from datetime import datetime

class Product(SQLModel, table=True):
    id: Optional[int] = Field(default=None, primary_key=True)
    name: str = Field(index=True)
    description: Optional[str] = None
    price: float
    stock: int = 0
    category: str
    created_at: datetime = Field(default_factory=datetime.utcnow)
    updated_at: datetime = Field(default_factory=datetime.utcnow)
```

### Key Features in Generated Code

1. **Excluded Fields**: `id`, `created_at`, `updated_at` not in Create/Update models
2. **Optional Fields**: `description` marked as optional
3. **Default Values**: `stock` has default value of 0
4. **Proper Routing**: `/products` endpoint with tag "products"

## CLI Usage Examples

### Basic Generation (Direct Pattern)

```bash
python scripts/generate_crud.py "
from sqlmodel import SQLModel, Field
from typing import Optional

class User(SQLModel, table=True):
    id: Optional[int] = Field(default=None, primary_key=True)
    name: str
    email: str
" > routers/user.py
```

### Repository Pattern with Existing Session

```bash
python scripts/generate_crud.py \
    models/product.py \
    --pattern repository \
    --session assume \
    -o routers/product.py
```

### Generate Multiple Routers

```bash
# Script to generate routers for all models
for model in models/*.py; do
    basename=$(basename "$model" .py)
    python scripts/generate_crud.py \
        "$model" \
        --pattern direct \
        --session generate \
        -o "routers/${basename}_router.py"
done
```

## Integration Example

### Register Generated Router in Main App

```python
from fastapi import FastAPI
from routers import user, product, post

app = FastAPI()

# Include generated routers
app.include_router(user.router)
app.include_router(product.router)
app.include_router(post.router)
```
